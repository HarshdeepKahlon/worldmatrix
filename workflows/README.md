## Workflows

This folder contains copy/paste workflows for common WorldMatrix tasks.

- `generate-wmx-assets.md`: batch-generate `asset.wmx.json` + variants + artifacts from a folder of models
- `run-dashboard.md`: run the dashboard (local mode and server mode)
- `integration-tests.md`: run the end-to-end integration test
- `r3f-demo.md`: run the R3F demo site that loads a `.wmx` manifest
- `three-imperative-demo.md`: run the imperative Three.js demo site using `@worldmatrix/wmx-runtime`
- `docker-compose-dashboard.md`: run asset-server + dashboard together in Docker Compose
- `integrations/three-imperative.md`: batteries-included runtime in a custom Three.js app
- `integrations/r3f.md`: batteries-included integration in a custom React Three Fiber app
- `integrations/nextjs.md`: Next.js App Router client-only integration patterns
- `offline-cache.md`: browser Service Worker disk caching for WMX `ultraLow` + `medium` (variants + streaming tiles) with a bounded budget
- `streaming-v1.md` (in `docs/spec/`): WMX streaming schema reference (`manifest.streaming`)
