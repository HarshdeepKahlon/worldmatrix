# Changesets

This repo uses Changesets for versioning and publishing selected public packages:

- `@worldmatrix/wmx-core`
- `@worldmatrix/wmx-three`
- `@worldmatrix/wmx-three-streaming`
- `@worldmatrix/wmx-runtime`
- `@worldmatrix/wmx-r3f`

## Commands

```bash
npm run changeset
npm run version-packages
```

To publish the selected packages after versioning:

```bash
npm run publish:wmx
```
